# StudyCore V1

Mobile-first prototype for the free Indian student platform.

Included:
- Class → Board → Stream → Subject → Chapter → Topic navigation
- Learn
- Practice
- Quiz
- Formula sheet
- Simple equation solver
- AI Tutor placeholder with a 3-question demo quota

The AI is NOT connected yet. Never put a private AI API key in frontend JavaScript.

Next phase: authentication + secure AI endpoint + database quota + larger curriculum.
